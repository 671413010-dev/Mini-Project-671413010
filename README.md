# VAJAX-TTS Web Application
ระบบสังเคราะห์เสียงพูดจำลองเสียงต้นแบบ (Voice Cloning / Text-to-Speech) โดยใช้บริการ API ของ AI For Thai

## คุณสมบัติเด่น (Features)
- 🎙️ **อัปโหลดหรือบันทึกเสียงสดผ่านไมโครโฟน**: บันทึกเสียงตัวอย่างแล้วแปลงเป็น WAV สำหรับใช้เป็น Reference Voice ได้ทันที
- 🎛️ **ปรับแต่งพารามิเตอร์ครบครัน**:
  - `speed`: ปรับความเร็วในการพูด (0.5 - 2.0)
  - `nfe_steps`: จำนวนขั้นตอน NFE สำหรับคุณภาพเสียง (16 - 64)
  - `seed`: ระบุเลขสุ่มเพื่อคงลักษณะเสียงเดิม หรือปล่อยว่างเพื่อให้ระบบสุ่ม
  - `use_phoneme`: รองรับการเปิด/ปิด Phoneme-based synthesis
- 🔊 **เล่นเสียงและดาวน์โหลดได้ทันที**: มี Audio Player ให้กดฟังและปุ่มดาวน์โหลดไฟล์ `.wav`
- 📊 **แสดง Metadata**: แสดงความยาวเสียง (Duration), Sample Rate, Seed, และเวลาประมวลผล (Processing time)

## การติดตั้งและเริ่มใช้งาน (How to Run)

### 1. ติดตั้ง Dependencies (หากยังไม่มี)
```bash
py -m pip install flask requests
```

### 2. รันแอปพลิเคชัน
```bash
py app.py
```

### 3. เข้าใช้งานผ่านเบราว์เซอร์
เปิดเบราว์เซอร์และเข้าไปที่:
```
http://localhost:5000
```
